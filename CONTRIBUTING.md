# Contributing to BustaSQL

Thanks for helping improve BustaSQL.

**This is a public releases and community repository, not the application source repository.** The main BustaSQL source is currently private. Contributions here can include documentation, translations, bug reports, accessibility feedback and feature ideas.

## Bugs

Use the [Bug report form](https://github.com/sensodent/BustaSQL-Releases/issues/new/choose). Search existing issues first. Include the BustaSQL version, Windows version, database engine and version, steps to reproduce, expected vs. actual results and (if useful) screenshots or sanitized logs.

**Remove server names, connection strings, passwords, tokens, query results with real data and any other sensitive information.** If you can, reproduce the problem with a minimal table and sample data instead. Do not report vulnerabilities publicly; see [SECURITY.md](SECURITY.md).

## Feature requests

Use the [Feature request form](https://github.com/sensodent/BustaSQL-Releases/issues/new/choose). Describe the problem and desired workflow, not just an implementation. Suggestions are not promises of delivery.

## Documentation pull requests

Documentation-only PRs to this public repository are welcome: fork the repository, make a focused change, keep `README.md` and `README.es.md` aligned where appropriate, and submit a PR using the template. Do not add application source, installer binaries, secrets, or materials you cannot redistribute. Official installers and update files are published by the release process.

## Questions and community standards

See [SUPPORT.md](SUPPORT.md), the [FAQ](FAQ.md), and the [Code of Conduct](CODE_OF_CONDUCT.md). You must have permission to contribute any submitted text or artwork.
