# Accessibility

BustaSQL is a desktop application built with Electron, React and the Monaco editor. Its custom views (object explorer, results grid, Schema and Data Compare, execution plans, table designer and AI assistant) may have accessibility issues even where the underlying components are accessible.

We aim to improve keyboard operation, contrast, focus behavior, zoom support (`Ctrl +` / `Ctrl −`) and screen-reader usability, but **do not currently claim audited WCAG conformance**.

To report a barrier, use the [Bug report form](https://github.com/sensodent/BustaSQL-Releases/issues/new/choose), prefix the title with `[Accessibility]`, and describe the workflow, assistive technology (if relevant), expected vs. actual result, version and steps to reproduce.

Please do not share sensitive medical or personal information.
